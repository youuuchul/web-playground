소개

저는 비즈니스 현장에서 발생하는 문제를 데이터로 구조화하고, 반복되는 의사결정/운영을 AI 에이전트로 자동화하는 데 관심이 있습니다. 특히 근거 기반 답변(grounding), 평가/품질관리, 운영 효율화에 집중합니다.

  • 문제정의/가설수립/검증/결과-제안 흐름으로 프로젝트를 정리합니다.
  • SQL·대시보드·리포트로 “의사결정의 재현성”을 만들고자 합니다.
  • LLM은 “정답 생성기”가 아니라 “업무 시스템의 구성요소”로 다룹니다.

현재 집중하는 주제

  • PEFT/LoRA: 제한된 자원에서 도메인 적응
  • RAG: 검색 품질(리트리벌) + 인용/근거 정합성
  • Inference-time scaling: 더 똑똑하게 “생각”시키는 설계
  • 평가: 자동평가(rouge 등) + 휴먼 캘리브레이션 + LLM-judge
