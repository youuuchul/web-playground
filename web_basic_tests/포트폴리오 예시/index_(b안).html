하는 일

비즈니스 문제를 ‘측정 가능한 질문’으로 바꾸기 Problem Definition

목표 지표/KPI 정의 → 가설 수립 → 데이터로 검증 → 실행 가능한 액션으로 연결합니다.

LLM + Tool 기반 에이전트 워크플로 설계 LLM Orchestration

검색(Retrieval), DB/API 호출, 검증(Verifier), 로그/모니터링까지 포함한 end-to-end 구조를 만듭니다.

데이터 파이프라인/리포팅 자동화 Automation

반복 업무를 줄이기 위한 쿼리/스케줄링/대시보드 흐름을 설계하고 운영 관점에서 안정화합니다.

일하는 방식

근거 중심 Grounded

“모르겠으면 모른다”를 기본으로, 가능한 한 출처/근거를 남기는 구조를 선호합니다.

작게 실험하고 빠르게 개선 Iterate

작은 MVP → 측정 → 개선을 반복합니다. 필요하면 test-time scaling으로 ‘생각 비용’을 조절합니다.

재현 가능한 시스템 Reproducible

버전/로그/데이터 스냅샷을 관리해 결과가 “다시 나오는” 분석·모델·에이전트를 지향합니다.

AI 에이전트 프로젝트 (예시)

문서 기반 Q&A 에이전트 RAG

사내/도메인 문서를 검색해 근거와 함께 답변. 인용-주장 정합성(grounding)을 강화.

리포트 자동 생성 에이전트 SQL + Summary

쿼리 실행 → KPI 요약 → 이상치/변동 원인 후보 생성 → 다음 액션 제안까지 자동화.

검증(Verifier) 루프 Reliability

모델 답변을 근거와 대조해 오류를 줄이는 레이어. 필요 시 답변 보류/추가 검색 수행.
